# 🇧🇩 Bangladesh 2.0  

A modern and responsive **Bangladesh Vision Landing Page** built using HTML and CSS. This project presents the idea of a futuristic Bangladesh through innovation, sustainability, and development-focused design.

---

## 🚀 Live Demo  
🔗 https://hoqueeprobal.github.io/Bangladesh-2.0/  

---

## 🚀 Features  
- ✅ Fully responsive design  
- ✅ Clean and modern user interface  
- ✅ Hero banner with call-to-action  
- ✅ Pillars of development section  
- ✅ Vision & future goals showcase  
- ✅ Inspirational quote section  
- ✅ Opinion survey with dropdown interaction  
- ✅ Recent news cards layout  
- ✅ Donation section with selectable amounts  
- ✅ Newsletter subscription form  
- ✅ Footer with social media links  
- ✅ Smooth hover effects and animations
